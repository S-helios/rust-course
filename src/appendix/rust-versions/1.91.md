# Rust 1.91（2025-10）

> 官方发布说明：[Announcing Rust 1.91.0](https://blog.rust-lang.org/2025/10/30/Rust-1.91.0/)

Rust 1.91 将 `aarch64-pc-windows-msvc` 提升为 Tier 1，Windows ARM64 工具链获得最高级别的发布和测试保障。

本版本还新增默认开启的 `dangling_pointers_from_locals` lint，用来发现从函数返回局部变量裸指针的高风险代码：

```rust
fn dangling() -> *const u8 {
    let value = 42;
    &value // 编译器会提示返回的裸指针可能悬空
}
```

裸指针本身不携带生命周期；不要把这个 lint 当成可以安全解引用的保证，跨函数传递数据时优先使用引用、拥有所有权的类型或智能指针。
