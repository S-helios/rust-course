# Rust 1.96（2026-05）

> 官方发布说明：[Announcing Rust 1.96.0](https://blog.rust-lang.org/2026/05/28/Rust-1.96.0/)

标准库引入 `core::range` 下的新 `Range`、`RangeFrom` 和 `RangeInclusive` 类型。它们实现 `IntoIterator` 而不是直接实现 `Iterator`，因此可以安全地派生 `Copy`，适合放入轻量的区间描述类型。

同时稳定了 `assert_matches!` 和 `debug_assert_matches!`：

```rust
use std::assert_matches::assert_matches;

assert_matches!(Some(3), Some(1..=6));
```

WebAssembly 目标不再默认把未定义链接符号当作 `env` 导入，链接配置错误会更早失败；只有明确需要旧行为时才通过链接参数重新开启。
