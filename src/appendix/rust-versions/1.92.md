# Rust 1.92（2025-12）

> 官方发布说明：[Announcing Rust 1.92.0](https://blog.rust-lang.org/2025/12/11/Rust-1.92.0/)

Rust 1.92 将两个与 never type 稳定化相关的未来兼容 lint 调整为 deny-by-default：

- `never_type_fallback_flowing_into_unsafe`
- `dependency_on_unit_never_type_fallback`

这类错误通常出现在依赖 `!` 或 `Infallible` 推导结果的泛型代码中。升级后应优先修正类型推导，不要用全局 `#[allow]` 隐藏问题。

`-Cpanic=abort` 在 Linux 上默认重新生成 unwind tables，因此崩溃回溯更可靠；如果明确不需要，可以使用 `-Cforce-unwind-tables=no` 关闭。
