# Rust 1.98（2026-08）

> 官方发布说明：[Announcing Rust 1.98.0](https://blog.rust-lang.org/2026/08/20/Rust-1.98.0/)

Rust 1.98 稳定了浮点数的代数运算方法，例如 `algebraic_add`、`algebraic_mul`。它们允许编译器利用实数代数性质重排计算以获得更好的向量化，但结果不保证与严格 IEEE 运算逐位一致：

```rust
let fast = a.algebraic_add(b).algebraic_add(c);
```

整数类型新增 `format_into`，可以直接写入固定大小的 `NumBuffer`，减少格式化过程中的动态分派。对延迟敏感的日志和序列化代码，可以用基准测试比较它与现有 `write!` 或 `itoa` 的差异。

> 1.98.1（2026-09-03）修复了 trait object vtable 生成中的一个错误。生产构建应至少使用 1.98.1，而不是 1.98.0。
